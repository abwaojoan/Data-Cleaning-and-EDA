Additional habits

  • Prefer scripts or notebooks that start from the raw file every time over manual spreadsheet edits.
  • Prefer median over mean for skewed numeric imputation.
  • Prefer explicit maps for category cleaning over silent string replacements.
  • When in doubt, flag suspicious rows instead of deleting them permanently.
