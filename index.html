Data Cleaning and Exploratory Data Analysis

Authors: Joan Abwao and Simon Wepukhulu
Date: 1 October 2026

This training material provides a clear, practical guide to preparing data for analysis. You will learn systematic methods for cleaning messy datasets and performing exploratory data analysis (EDA) using Python and pandas. The content is designed for learners who already know basic Python and want to build reliable, reproducible data workflows.

All pages are static and read-only. You can host this site on GitHub Pages or any static file server. Interactive checklists save progress in your browser.

Learning Objectives

  • Inspect a new dataset systematically before making changes.
  • Choose appropriate strategies for missing values, duplicates and outliers.
  • Convert data types and standardize text and dates.
  • Apply tidy data principles so datasets are easy to analyse.
  • Perform core EDA steps: summaries, distributions and relationships.
  • Document cleaning decisions and keep raw data untouched.
Prerequisites Basic Python, familiarity with pandas DataFrames, and a working Python environment (Jupyter, VS Code, or similar). Sample code assumes pandas and matplotlib or seaborn are installed.
