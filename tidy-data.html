6. Tidy Data Principles

Tidy data, formalised by Hadley Wickham, is a standard way to structure tables so that analysis tools work consistently. A tidy dataset has three properties:

  1. Each variable forms a column.
  2. Each observation forms a row.
  3. Each type of observational unit forms a table.

Messy data often violates these rules: column headers contain values, multiple variables sit in one column, or different entities are mixed in the same table.

Common messiness and fixes (pandas)

Column headers are values

# Wide format: years as columns
# id | 2020 | 2021 | 2022
#  a |  10  |  12  |  15

tidy = df.melt(
    id_vars=["id"],
    var_name="year",
    value_name="value"
)
# Result: id | year | value

Multiple variables in one column

# Example: "male_10" style labels
df[["sex", "age_group"]] = df["group"].str.split("_", expand=True)

Variables stored in both rows and columns

Use a combination of melt and pivot (or pivot_table) to rearrange until each variable is its own column and each observation is a single row.

Why tidy data helps Most visualisation and modelling functions expect one observation per row and one variable per column. Once data is tidy, the same small set of tools works for almost every subsequent step.

For a full treatment see Wickham (2014), "Tidy Data", Journal of Statistical Software (linked on the References page).
