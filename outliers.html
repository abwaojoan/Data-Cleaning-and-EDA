5. Identifying and Treating Outliers

Outliers are values that sit far from the bulk of the data. Some are genuine extremes (high earners, rare events). Others are errors (typos, sensor faults). The goal is to distinguish the two before deciding what to do.

Detection methods

IQR method

def find_outliers_iqr(series):
    q1 = series.quantile(0.25)
    q3 = series.quantile(0.75)
    iqr = q3 - q1
    lower = q1 - 1.5 * iqr
    upper = q3 + 1.5 * iqr
    return series[(series < lower) | (series > upper)], lower, upper

outliers, lo, hi = find_outliers_iqr(df["salary"])
print(f"Outliers: {len(outliers)}, bounds: [{lo:.1f}, {hi:.1f}]")

Z-score method

from scipy import stats
z = stats.zscore(df["salary"].dropna())
outliers_z = df["salary"].dropna()[abs(z) > 3]
print("Z-score outliers:", len(outliers_z))

Visual checks

import matplotlib.pyplot as plt
import seaborn as sns

fig, axes = plt.subplots(1, 2, figsize=(10, 4))
sns.boxplot(x=df["salary"], ax=axes[0])
sns.histplot(df["salary"], bins=30, ax=axes[1])
plt.tight_layout()
plt.show()

Treatment options

  • Investigate: look at the full row. Domain knowledge decides if the value is possible.
  • Correct: fix obvious typos (for example 1000000 instead of 100000).
  • Cap (winsorise): set values beyond the bounds to the bound itself.
  • Remove: only when the observation is clearly erroneous and not informative.
  • Keep and model robustly: use methods less sensitive to extremes (median, robust regression).
# Cap using IQR bounds
q1 = df["salary"].quantile(0.25)
q3 = df["salary"].quantile(0.75)
iqr = q3 - q1
lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr
df["salary_capped"] = df["salary"].clip(lower=lower, upper=upper)
Caution Blindly removing outliers can hide important signals or introduce selection bias. Always document the rule and the number of rows affected.
