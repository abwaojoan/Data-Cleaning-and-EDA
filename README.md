# Data Cleaning and Exploratory Data Analysis Tutorial

**Authors:** Joan Abwao and Simon Wepukhulu  
**Date:** 1 October 2026

A clear, concise, interactive training website on data cleaning and exploratory data analysis (EDA) using Python and pandas.

## Features

- Multi-page static site (works offline and on GitHub Pages)
- Hyperlinked table of contents and navigation
- Copy-to-clipboard code blocks
- Interactive workflow checklist (progress saved in browser)
- Professional teal colour scheme
- Full references included

## Contents

1. Introduction to Data Cleaning and EDA  
2. Handling Missing Values  
3. Detecting and Removing Duplicates  
4. Data Types, Formatting and Standardization  
5. Identifying and Treating Outliers  
6. Tidy Data Principles  
7. Exploratory Data Analysis Techniques  
8. Best Practices and Workflow Checklist  
9. References and Further Reading  

## How to use

### Local viewing

Open `index.html` in any modern browser, or serve the folder:

```bash
# Python
python -m http.server 8000

# Then visit http://localhost:8000
```

### GitHub Pages

1. Create a new repository (public or private).
2. Upload the contents of this folder (or push via git).
3. In repository Settings → Pages, set Source to the branch containing these files (usually `main`) and the root folder `/`.
4. After a minute or two the site will be live at `https://<username>.github.io/<repo-name>/`.
