4. Data Types, Formatting and Standardization

Correct data types enable proper calculations and reduce memory use. Inconsistent text, mixed date formats and numbers stored as strings are common sources of silent errors.

Inspect and convert types

print(df.dtypes)

# Convert numeric columns that were read as object
df["amount"] = pd.to_numeric(df["amount"], errors="coerce")

# Convert dates
df["join_date"] = pd.to_datetime(df["join_date"], errors="coerce", dayfirst=False)

# Category for low-cardinality strings (saves memory and helps modelling)
df["department"] = df["department"].astype("category")

Clean column names

df.columns = (
    df.columns
    .str.strip()
    .str.lower()
    .str.replace(r"\s+", "_", regex=True)
    .str.replace(r"[^\w]", "", regex=True)
)

Standardise text

# Lowercase, strip, collapse spaces
df["city"] = (
    df["city"]
    .str.lower()
    .str.strip()
    .str.replace(r"\s+", " ", regex=True)
)

# Map inconsistent categories
status_map = {
    "active": "Active",
    "ACTIVE": "Active",
    "act": "Active",
    "inactive": "Inactive",
    "INACT": "Inactive"
}
df["status"] = df["status"].str.strip().str.lower().map(status_map).fillna(df["status"])

Parse mixed formats

Dates or currencies often arrive in several formats. Use pd.to_datetime with errors="coerce" and inspect the resulting NaT values. For currency, strip symbols and convert to numeric. 

# Example: clean currency strings
df["spend"] = (
    df["spend"]
    .astype(str)
    .str.replace(r"[$,]", "", regex=True)
    .str.strip()
)
df["spend"] = pd.to_numeric(df["spend"], errors="coerce")
Tip After every conversion, re-check df.info() and look at rows that became NaN or NaT. Those rows often hide the remaining format problems.
