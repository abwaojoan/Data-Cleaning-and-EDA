2. Handling Missing Values

Missing values appear as NaN, None, empty strings, or sentinel codes such as -999 or "N/A". How you treat them depends on why they are missing and how much is missing.

Types of missingness

  • MCAR (Missing Completely at Random): no systematic reason. Imputation is relatively safe.
  • MAR (Missing at Random): missingness depends on other observed variables. Model-based methods help.
  • MNAR (Missing Not at Random): missingness depends on the unobserved value itself. Requires domain knowledge or extra data.

Inspect first

# Count missing values
print(df.isnull().sum())
print((df.isnull().mean() * 100).round(2))  # percentage

# Visual overview (optional)
import seaborn as sns
import matplotlib.pyplot as plt
sns.heatmap(df.isnull(), cbar=False, yticklabels=False, cmap="viridis")
plt.title("Missing values heatmap")
plt.show()

Common strategies

Strategy When to use pandas example
Drop rows Few missing rows and no critical bias df.dropna(subset=["key_col"])
Drop columns More than ~50% missing and low value df = df.loc[:, df.isnull().mean() < 0.5]
Fill with median / mode Numeric (median) or categorical (mode), roughly MCAR df["age"].fillna(df["age"].median())
Forward / backward fill Time series or ordered data df["val"].ffill()
Indicator flag Missingness itself is informative df["age_missing"] = df["age"].isnull()
Caution Filling with the mean can distort skewed distributions. Prefer the median for numeric columns that are not symmetric. Never fill without checking the pattern of missingness.

Worked example

# Drop rows where critical ID is missing
df = df.dropna(subset=["customer_id"])

# Drop columns with more than 50% missing
df = df.loc[:, df.isnull().mean() < 0.5]

# Impute numeric with median, categorical with mode
for col in df.select_dtypes(include="number").columns:
    df[col] = df[col].fillna(df[col].median())

for col in df.select_dtypes(include="object").columns:
    mode_val = df[col].mode()
    if not mode_val.empty:
        df[col] = df[col].fillna(mode_val[0])
    else:
        df[col] = df[col].fillna("Unknown")

print("Remaining nulls:", df.isnull().sum().sum())
