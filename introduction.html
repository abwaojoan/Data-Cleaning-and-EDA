1. Introduction to Data Cleaning and EDA

Real-world data is almost never ready for analysis. Missing entries, inconsistent formats, duplicate records, and unexpected values are common. Data cleaning (also called data wrangling or data preparation) turns raw data into a reliable table that supports sound analysis and modelling.

Exploratory Data Analysis (EDA) is the process of understanding a dataset: its structure, distributions, relationships and quality issues. EDA and cleaning form a loop. You explore to find problems, clean to fix them, then explore again to confirm the fixes and discover new patterns.

Why this matters

  • Garbage in, garbage out: models and statistics inherit the quality of the input data.
  • Most of a data project is spent on preparation, often 60 to 80 percent of the effort.
  • Documented, repeatable cleaning protects you from silent bias and makes work reproducible.

A practical workflow

  1. Ingest and inspect: load the data, check shape, types, sample rows and basic counts.
  2. Identify issues: missing values, duplicates, wrong types, outliers, inconsistent labels.
  3. Plan transformations: decide whether to drop, impute, correct or flag. Record the reason.
  4. Apply and verify: run the changes and check that row counts and key totals still make sense.
  5. Explore: summarise, visualise and study relationships on the cleaned data.
Tip Always keep an untouched copy of the raw data. Work on a copy or in a pipeline that starts from the original file every time.

Quick start with pandas

import pandas as pd

# Load data
df = pd.read_csv("data.csv")

# First look
print(df.shape)
print(df.head())
print(df.info())
print(df.describe(include="all"))
print(df.isnull().sum())
print(df.duplicated().sum())

These few commands give you structure, types, missingness, basic statistics and exact duplicate counts. They form the starting point for every later step in this tutorial.
