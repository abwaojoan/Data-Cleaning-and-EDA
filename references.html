9. References and Further Reading

The following sources informed the content of this tutorial. They are recommended for deeper study.

  1. Wickham, H. (2014). Tidy Data. Journal of Statistical Software, 59(10), 1-23.
    https://doi.org/10.18637/jss.v059.i10 (also available at vita.had.co.nz)
  2. McKinney, W. (2022). Python for Data Analysis (3rd ed.). O'Reilly Media. Chapter 7 covers data cleaning and preparation with pandas.
    https://wesmckinney.com/book/data-cleaning
  3. pandas development team. pandas documentation: Working with missing data and data types.
    https://pandas.pydata.org/docs/user_guide/missing_data.html
  4. Wickham, H., & Grolemund, G. R for Data Science (2nd ed.). Chapter on tidy data (concepts transfer directly to pandas).
    https://r4ds.hadley.nz/data-tidy.html
  5. University of California, Berkeley. Data 100 course notes: Data Cleaning and EDA.
    https://ds100.org/course-notes-su23/eda/eda.html
  6. Chicco, D., Oneto, L., & Tavazzi, E. (2022). Eleven quick tips for data cleaning and feature engineering. PLoS Computational Biology, 18(12), e1010718.
    https://doi.org/10.1371/journal.pcbi.1010718
  7. KDnuggets and Towards Data Science tutorials on practical pandas cleaning workflows (search for "data cleaning pandas" for current examples). Useful for additional code patterns.

Suggested practice datasets

  • UCI Machine Learning Repository (Adult, Titanic-style tabular sets).
  • Kaggle public datasets with known quality issues (search "messy data").
  • Your own organisational exports (anonymised) for realistic practice.
