3. Detecting and Removing Duplicates

Duplicate rows inflate counts, bias averages and can break uniqueness constraints. Exact duplicates are easy to find. Near-duplicates (same person, slightly different spelling) need extra care and often domain rules.

Exact duplicates

# Count exact duplicate rows (all columns)
print("Exact duplicates:", df.duplicated().sum())

# View them
df[df.duplicated(keep=False)].sort_values(by=list(df.columns))

# Remove, keeping the first occurrence
df = df.drop_duplicates()

# Or keep the last occurrence
df = df.drop_duplicates(keep="last")

Duplicates on key columns

Sometimes only a subset of columns should be unique (for example customer_id + order_date). 

# Check duplicates on specific columns
print(df.duplicated(subset=["customer_id", "order_date"]).sum())

# Drop them
df = df.drop_duplicates(subset=["customer_id", "order_date"], keep="first")

Near-duplicates

Standardise text first (lowercase, strip whitespace, normalise punctuation), then compare on the cleaned keys. For names or addresses you may need fuzzy matching libraries, but start with simple standardisation. 

# Simple standardisation before checking
df["name_clean"] = (
    df["name"]
    .str.lower()
    .str.strip()
    .str.replace(r"\s+", " ", regex=True)
)

print(df.duplicated(subset=["name_clean"]).sum())
Decision rule Ask: is the duplicate a true repeated observation or a data entry error? Keep legitimate repeats (for example multiple visits by the same customer) and remove accidental copies. Document the rule you use.
